* You can now view all of details of the CIP files (Application Control binaries) directly in the File Explorer's preview pane, as if they are plain text files! AppControl Manager previews any CIP file for you simply by selecting it in File Explorer and then opening the Preview pane. This makes it extremely easy to inspect and analyze the contents of CIP files without needing to open a separate application.

* The scan level fallbacks configurations you make are now persisted in the app settings and they will no longer reset. You can also use backup and restore feature in the settings page to reapply them to any other app instance. Completes the following feature request: https://github.com/HotCakeX/Harden-Windows-Security/issues/1209
