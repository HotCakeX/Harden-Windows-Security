## TopBar V2

* When you're in the Performance view of the TopBar and the notch is in the normal/default size, it now displays the real-time CPU and RAM usage of any application or program you are currently working on. For example, if you are watching a vidoe on Edge or coding in Visual Studio, you see the active CPU/RAM usage of them.

* Just like the Folders section, you can now drag and drop files over the TopBar in order to add/pin them to the Apps section. Additionally, any file or app you add to the Apps section will have its native icon/thumbnail that you normally see in the File Explorer.

* You can now assign any custom color to the folders you add to the TopBar, making it easier for you to personalize it and find what you are looking for faster. Your changes are saved and remembered in the app's settings.

* You can now select multiple files/apps/folders when using the plus icon to add them to the TopBar; Previously this could only be done one by one.

* You can now search inside each of the folders you've added to the TopBar by right-clicking on them and selecting "Search". You can drag and drop the search results to other apps or right-click/Tap-Hold on them to open them in File Explorer, improving the overall user productivity.

* Improved the TopBar's ability to stay on top of other windows.

* Improved keyboard navigation in the TopBar: you can now use arrow keys to navigate it.

## Others

* Updated dependencies to the latest versions.
