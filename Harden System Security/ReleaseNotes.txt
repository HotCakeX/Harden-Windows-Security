## Windows Top Bar

Introduced a new Windows Top Bar, a customizable desktop toolbar with shortcuts, pinned folders, live system metrics, world clocks, multiple notch styles, and responsive positioning across display and resolution changes.

## Feature Highlights Carousel

Added a new Feature Highlights carousel showcasing prominent app capabilities through an interactive visual experience. The carousel opens automatically on first launch and remains accessible anytime from the main window toolbar.

## MCP Server for AI Workflows

Created a dedicated app that offers MCP Server capabilities through the Harden System Security app. It is very lightweight (only 1 MB package size) and can be installed from the Microsoft Store: https://apps.microsoft.com/detail/9P3BDTHKR7KS

It depends on the main Harden System Security app to be installed in order to function. It acts as a relay between AI models (such as GPT or Grok) and the Harden System Security app, allowing users to leverage AI capabilities while maintaining system security.

You can add the MCP Server to the Visual Studio Code, GitHub Copilot app and any other program that supports MCP Server integration.

Once the apps are installed, you can ask the AI models to Harden your Windows by applying security measures, Verify the security hardening of your Windows and receive secure score with details, and/or remove them.
