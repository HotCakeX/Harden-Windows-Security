* Updated dependencies to the latest versions.

* New features for the Package Manager in the Update page:

    * Remove package signature: You can now remove the signature (signing certificate) of any MSIX/MSIXBundle packages. It's useful if you've signed your package with a certificate and now you want to sign it with another.

    * Explore package content: Simply browse for any MSIX/MSIXBundle package to view its content and file sizes in a File Explorer like environment.

    * Edit package versions: Select any MSIX/MSIXBundle package to edit its version without having to recompile your program from scratch. In case of MSIXBundles, you can separately edit the bundle's version and also every individual package inside of it, giving you great flexibility. Keep in mind that editing a package's version removes its signature (if any) because it's been modified.

    * Any modification to the packages is thoroughly validated to ensure package integrity remains intact and no unwanted changes have happened during the editing process.
