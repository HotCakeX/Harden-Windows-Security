* The TopBar's search results now contain a small thumbnail of each file or folder in the results, helping you further with identifying them.

* Improved keyboard handling in the Topbar's websites view.

* Significantly improved the Global Search's performance.

* Based on user feedback, the position of the main app menu is now remembered: Left or Top.

* The Global Search's indexing feature is now disabled by default and will only activate as soon as you start typing something in the search area. You can configure this with the new option available in the TopBar. Resolves the following issue: https://github.com/HotCakeX/Harden-Windows-Security/issues/1233

* The Global Search now offers a new feature that lets you generate an interactive Pie chart for each of your drives to see the distribution of file types, helping you quickly identify which areas are taking up the most space.
