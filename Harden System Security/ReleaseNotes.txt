## Compatibility Improvements

- Improved support for installations where the app is installed for a Standard user account and elevated in place using an Administrator account's credentials. The following features are now available in this configuration:
  - Displaying toast notifications
  - Displaying taskbar icon badges for activities in progress
  - Pinning the app to the taskbar
  - Pinning the app to the Start menu

- Toast notifications are now displayed even when the app is running with elevated privileges.

These improvements provide more consistent behavior across different account and elevation configurations, resulting in a more reliable and unified experience. They also make the app more compatible with the new Administrator Protection feature in Windows.

## New Notification Settings

- Added a new **Notifications** section to the **Settings** page that allows you to:
  - Enable or disable toast notifications from the app
  - Clear all notifications created by the app from Windows Notification Center

## New Toast Notifications

* A toast notification is now displayed when a download is completed in the Download Manager, showing you the name of the file and where it was saved.
* A toast notification is displayed when the security verification is completed in the Protect page, showing you the security score of the system and counts of the items that were compliant vs non-compliant.
