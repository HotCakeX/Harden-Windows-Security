# Changes in the DNS Page

* The contacted domains log file path is now saved in the app settings.

* Adjusted the pre-selected list of upstream DNS resolvers.

* Added handling for an issue in the Kestrel's HTTP/3 Quic for DNS over HTTPS. The DoH server in the Harden System Security app fully supports HTTP/3 communication and can be used for the Secure DNS in the Edge or other browsers to make your website lookups private and secure.

# Other Changes

* Set the default backdrop material style of the app to Mica (Previous it was Mica Alt by default) and the menu icons are set to animated instead of monochrome. This change is only for when the app is installed for the first time. Your preferences are unchanged and saved as before and you can change any of the default values in the app's settings page.
